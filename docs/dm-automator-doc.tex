\section{What Is This Tool?}

DM Automator is a self-hosted automation tool built by \textbf{Leadfreak} for social media influencers and content creators.

\textbf{Problem:} An influencer posts a reel and says \textit{``Comment MATERIAL to get the PDF''}. Thousands of people comment. Sending a DM to each one manually is impossible at scale.

\textbf{Solution:} This tool automatically detects keyword comments and instantly sends the material via DM --- without relying on any third-party tools (ManyChat, MobileMonkey, etc.).

\begin{tcolorbox}[colback=blue!3, colframe=pri, boxrule=0.4pt]
\textbf{Supported Platforms:} Instagram (fully automated DM) + LinkedIn (semi-automated)\\[0.2em]
\textbf{Material Types:} PDF links, Google Drive links, text messages, image URLs --- anything
\end{tcolorbox}

% ============ SECTION 2 ============
\section{Workflow --- How It Works}

\subsection{Instagram (Fully Automated)}

\begin{tcolorbox}[colback=blue!2, colframe=pri!60, boxrule=0.3pt]
\begin{enumerate}[leftmargin=1.5em, itemsep=0.4em]
    \item You publish a post or reel on Instagram
    \item You create a \textbf{Campaign} on the dashboard --- post ID + keyword + material
    \item A user comments ``\texttt{MATERIAL}'' on that post
    \item Instagram sends a \textbf{webhook} notification to our server instantly
    \item The server performs a keyword match
    \item \textbf{The DM is sent automatically} to the user's inbox
\end{enumerate}
\end{tcolorbox}

\begin{tcolorbox}[colback=red!3, colframe=red!50, boxrule=0.4pt, title={\small Instagram Limitation}]
The Instagram Messaging API only allows sending a DM if the user has \textbf{messaged your business account within the last 24 hours}. If this window is not open, the DM is marked as \texttt{skipped} and shown on the dashboard. This is a Meta platform restriction, not a tool limitation.
\end{tcolorbox}

\subsection{LinkedIn (Semi-Automated)}

LinkedIn's Messaging API is restricted to select partners only. Therefore, a \textbf{poll-and-notify} model is used:

\begin{enumerate}[leftmargin=1.5em, itemsep=0.3em]
    \item The tool checks post comments every \textbf{5 minutes} via polling
    \item When a keyword match is found, the user appears on the \textbf{dashboard}
    \item You can then either:
    \begin{itemize}[itemsep=0.2em]
        \item \textbf{Send a manual DM} --- the profile link is provided on the dashboard
        \item \textbf{Auto-reply to their comment} with the material link --- this is automated
    \end{itemize}
\end{enumerate}

\section{Requirements for Going Live}

\subsection{Instagram Setup}

\begin{enumerate}[leftmargin=1.5em, itemsep=0.3em]
    \item \textbf{Instagram Business or Creator Account} --- a personal account will not work
    \item \textbf{Facebook Page} connected to the Instagram account
    \item \textbf{Meta Developer App} --- create one for free at \texttt{developers.facebook.com}
    \begin{itemize}[itemsep=0.2em]
        \item Add the ``Instagram'' product to the app
        \item Set the webhook URL: \texttt{https://your-server-ip/webhooks/instagram}
        \item Subscribe to the \texttt{comments} field
    \end{itemize}
    \item \textbf{Permissions} (enable these in the Meta App):
    \begin{itemize}[itemsep=0.2em]
        \item \texttt{instagram\_business\_basic}
        \item \texttt{instagram\_business\_manage\_messages}
        \item \texttt{instagram\_business\_manage\_comments}
    \end{itemize}
    \item \textbf{Page Access Token} --- generate from the Meta Developer portal (valid for 60 days, must be refreshed)
\end{enumerate}

\begin{tcolorbox}[colback=blue!3, colframe=pri, boxrule=0.4pt]
\textbf{Note:} If you are only using your own account, \textit{Standard Access} is sufficient --- no app review is required. For third-party accounts, \textit{Advanced Access} is needed (requires Meta review).
\end{tcolorbox}

\subsection{LinkedIn Setup}

\begin{enumerate}[leftmargin=1.5em, itemsep=0.3em]
    \item \textbf{LinkedIn Company Page} (Organization)
    \item \textbf{LinkedIn Developer App} --- create for free at \texttt{linkedin.com/developers}
    \begin{itemize}[itemsep=0.2em]
        \item Request the ``Community Management API'' product
        \item Associate the app with your Company Page
    \end{itemize}
    \item \textbf{Permissions}: \texttt{r\_organization\_social} (read) + \texttt{w\_organization\_social} (write)
    \item \textbf{OAuth2 Access Token} --- valid for 60 days
\end{enumerate}

\section{Quick Start Guide}

\begin{enumerate}[leftmargin=1.5em, itemsep=0.6em]
    \item \textbf{Install dependencies:}\\
    \texttt{cd \textasciitilde/dm-automator \&\& pip install -r requirements.txt}

    \item \textbf{Configure environment:}\\
    \texttt{cp .env.example .env}\\
    Open the \texttt{.env} file and enter your API tokens (IG token, Meta App Secret, etc.)

    \item \textbf{Start the server:}\\
    \texttt{uvicorn main:app --reload --port 8000}

    \item \textbf{Open the dashboard:} \texttt{http://localhost:8000}
    \begin{itemize}[itemsep=0.2em]
        \item Log in with default credentials: \texttt{admin@example.com} / \texttt{changeme123}
        \item Go to \textbf{Settings} and paste your Instagram / LinkedIn tokens
        \item Create a \textbf{New Campaign} --- select platform, enter post ID, keyword, and material
        \item Done! Whenever someone comments the keyword, the material will be sent automatically
    \end{itemize}
\end{enumerate}
